## Demonstrated defects and generic corrections

1. **Canonical URL identity mismatch in research.** The saved Vancity LOC registry
   contained `/rates#prime`; research proposed `/rates`. SourceRegistry correctly
   treats them as one source, but the research planner compared literal strings.
   The planner now normalizes attempted URLs and includes every registry identity
   before selecting another source. Fragment, tracking and default-port variants
   cannot duplicate/retry a source; priced query identities remain distinct.
2. **Lost successful static evidence during optional browser enhancement.**
   NonRetryableFetchError, including exhausted browser allowance, previously
   escaped and discarded an already successful HTTP body. Best-effort enhancement
   now retains that body and its failure diagnostics. Actual access challenges
   still fail closed. Existing browser/research budgets are unchanged.
3. **Independent native identity was vetoed by tentative discovery.** Vancity
   Jumpstart had the correct tentative name but `product_identity_match=false`.
   The old path accepted strong native H1/title/route/financial-record proof only
   when there was no tentative name. Strong native proof now applies independently;
   actual source, snapshot, bank, country and language checks remain mandatory.
4. **Named dated account rows and their annual-unit disclosure were lost.** The
   current Vancity rate page explicitly names Jumpstart `(all balances)` with
   0.60%, a dated `Accounts` table, annual-rate declaration and daily-calculation /
   monthly-payment sentence. A shared native record preserves the exact owner,
   date, percent, whole disclosure and local references. It rejects tiers,
   qualifications, competing annual notes, unresolved references and placeholders.
5. **Owned card labels and page-wide annual units were not joined.** TD uses
   literal `Interest: Purchases` / `Interest: Cash Advances` labels. The native
   labelled-record path now accepts these labels and retains the complete exact
   annual-rate declaration, including observed repeated effective-date statements.
   The annual note supplies units only; it supplies no price or removed condition.
   The optional comma after the date is formatting, not a financial distinction.
6. **Nonbreaking spaces defeated exact owned-name equality.** TD Cash Back Visa
   had the same product name with a nonbreaking space. Label ownership comparisons
   normalize whitespace only. Different named panels and meaningful Plus variants
   remain distinct; actual source origins are still checked.
7. **Annual rate units were misclassified as annual payout options.** The
   normalization frequency filter counted `annual interest rate` alongside
   `paid monthly` as two payout options and silently deleted verified monthly
   payment. It now distinguishes annual interest payments/payouts from annual
   rate units. Actual multiple payout choices and loan repayment contexts still
   reject; the actual Jumpstart artifact preserves both calculation and payment.
8. **Missing owned modal notes were not an essential acquisition signal.** A
   current TD checking capture contains an owned transaction label with a
   superscript link to a modal absent from the static DOM. The planner can now
   request one existing-budget render for that missing required disclosure.
   Optional-only, already attempted/rendered, resolved and other-panel cases do
   not request rendering. The financial gate still excludes the actual incomplete
   TD capture; no transaction allowance is inferred.
9. **Irrelevant prudential disclosures consumed essential research.** WEALTHONE
   research selected a Basel/Pillar 3 capital report rather than account terms.
   Generic prudential/capital-adequacy link signals now exclude those leads.
   Actual account/rate legal disclosures remain eligible within the same budget.

10. **Configured targets incorrectly became an optional-fact ceiling.** A source
    configuration with no optional targets discarded calculation/monthly-payment
    facts already proved by the same complete rate record. Shared native extraction
    now preserves proved profile supplemental facts alongside the existing
    registered card optional facts. Configuration still bounds targeting; this
    adds no research, capture, model call or new publication requirement.

There are no bank-name or bank-value acceptance branches. New source fixtures and

`2026-10-08-owned-source-identity-proof-v9` are aligned. Units, exact term boundaries,

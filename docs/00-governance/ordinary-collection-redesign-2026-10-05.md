## New ordinary process and protected boundaries

1. Keep the operator-selected product targets and initial safe capture/parse.
2. Bind only successful current-run owned detail/companion inputs. Reuse the
   production captured-field proof and unchanged financial sanitizer to identify
   missing applicable required fields, including configured additional fields.
3. Inspect literal observed links on those actual captures. Apply existing
   domain, market, action and unrelated-document vetoes. A planner may select
   only supplied link IDs; it cannot create URLs, values or accepted facts.
4. Append selected evidence-only companions to the immutable scratch Run plan;
   use normal snapshot/parse stages and actual document/snapshot/parse lineage.
   Reassess essentials after capture, including a second captured HTML hop.
5. Run the existing single final field-grounding pass per detail, then actual
   extraction-artifact loading, current-run origin resolution, normalization,
   automatic validation and the unchanged promotion/Public projection stages.

Hard limits are two acquisition waves, two additional URLs per detail, 48 per
Run, and eight planner invocations per Run. Every attempted URL consumes the
budget and is never selected again within this research process. Existing
snapshot-stage safe-fetch/retry controls remain unchanged. Provider invalidity
or failure may use deterministic observed-link selection, without a paid planner
retry. Unsupported sources or exhausted budgets remain diagnostic exclusions.

Only required-evidence gaps trigger research. Typed optional facts proved in the
same evidence remain collected and preserved; optional absence does not trigger
research, become false/zero or penalize ranking. No manual product review,
financial default expansion, security change, new market/type, raw public
evidence, canonical bypass or permanent recovery feature is introduced.

The current CIBC regression established its exact native H1 before extending
identity proof. It requires the owned main section, owned labelled price,
matching current document/snapshot/parse/language and at least two distinctive
name terms on the product URL. Action URLs, family pages, missing records and
foreign origins remain rejected. Extraction instructions use the same rule.
A localized Legal link is a retrieval lead only; it never proves a rate.

Independently captured named annual-unit terms are now explicit evidence links
for the rate field in extracted JSON. The production CLI loader and normal
current-run origin lookup retain their full text, anchor, source URL, document
and snapshot. Their validity still depends on the unchanged named-product,
annual-basis and complete-context checks. A separate optional or currency link
cannot be the only means of retaining that required reference.

Private ingestion Run metadata retains assessments, selected capture lineage,
planner usage, acquisition/parse failures and stopping reasons. Process version
is 2026-10-05-evidence-research-v1 in new Run receipts and the additive health
field collection_process_version. Accuracy and market-profile versions retain
their own meanings; preflight diagnostics are not approval receipts or bank
nondisclosure findings. Failed companions cannot remove already successful
original inputs or become product targets.

# 히고은행·가고시마은행 상품 수집 준비 점검

2026-11-21 기준, 개인·법인·개인사업자에게 두 은행이 직접 제공하는 금융상품을 대상으로 했다. 개발 DB에서 일본과 두 은행의 수집 범위를 등록했다. 전상품 일괄 수집은 아직 준비되지 않았다.

## 공식 출처와 확인 범위

| 은행 | 공식 설명서 목록 | 추가 대조 범위 | FPDS에서 확인한 상태 |
| --- | --- | --- | --- |
| 히고은행 | 54개 표기 항목. 신규 취급 중지·종료 표기 8개 포함 | 법인 자금조달·예금·외환, 자체 데빗카드, 별도 대출 상세까지 총 82개 출처 행 | 현재 실행 환경에서 목록 직접 요청과 표본 PDF가 HTTP 403이었다. 기존 브라우저 처리에서 목록이 HTTP 200을 반환했으나 본문은 324바이트의 접근 거부 안내였다. |
| 가고시마은행 | 56개 표기 항목. 주택대출 2개의 이미지 링크와 텍스트 링크가 달라 별도 주택대출 목록에서 확인 | 법인 자금조달, 데빗카드, 지속가능금융 발표까지 총 67개 출처 행 | 설명서 목록과 대출 PDF 2개를 읽었다. 카드론 S의 상환계좌 불필요형은 원문 재생으로 검증했다. |

각 행에는 은행, 일본어 표기명, 목록 URL, 상세 URL, 탐색할 상품 유형, 처리 상태를 기록했다. 149행에는 같은 문서의 재등장, 취급 종료, 서비스 안내, 제공 주체 또는 계약 확인이 필요한 항목이 포함된다. 이 숫자로 영업 중인 고유 상품 수나 수집률을 산정할 수 없다. [출처 대조표](../../worker/discovery/data/jp_higo_kagoshima_listings.csv)

- 히고은행의 법인 외화보통예금과 개인용 외화저축예금은 고객 대상이 다르다. 외화 대출, 무역보증, 신용장과 지급결제 서비스도 구별해야 한다. [상품설명서](https://www.higobank.co.jp/individual/description.html) · [법인 자금조달](https://www.higobank.co.jp/business/service/funding/) · [법인 예금](https://www.higobank.co.jp/business/service/operation/) · [법인 외환](https://www.higobank.co.jp/business/service/support/international/exchange.html)
- 가고시마은행의 종합 목록은 예금·가계대출·외환 설명서를 연결한다. 법인 전용 대출과 별도 주택대출 목록도 대조했다. 보증기관이 따로 있어도 대출 제공 주체가 은행이면 범위에 포함된다. [상품설명서](https://www.kagin.co.jp/kojin/savings/100_016.html) · [법인 자금조달](https://www.kagin.co.jp/houjin/202_support.html) · [주택대출 설명서](https://www.kagin.co.jp/kojin/loan/housing/loan_list.html)
- 제휴카드는 계약 주체와 신규 신청 상태를 확인했다. 히고 Harmonica JCB의 신용 기능은 계열 카드사와 JCB 발행 조건을 따른다. 가고시마는 MOZECA 신규 신청 종료를 별도로 공지했다. 두 건을 은행의 신규 자체 신용카드로 등록하지 않았다. [히고 카드 특약](https://www.higobank.co.jp/individual/pdf/kitei_cashjcb.pdf) · [가고시마 신규 발급 종료 공지](https://www.kagin.co.jp/important/20251111_053.html)

## 개발 DB와 수집 경로

개발 DB에 활성 국가 JP, 일본어 은행 HIGO·KAGOSHIMA, JP 분류 8개, 은행별 공식 목록 8개씩을 확인했다. 유형은 결제성예금, 저축예금, 정기예금, 주택대출, 개인대출, 개인 한도대출, 사업자대출, 사업자 한도대출이다. 두 사업자 유형은 별도 코드로 등록했다. 같은 국가·은행·유형이 다른 출처에 이미 등록돼 있으면 등록 작업 전체가 중단된다. 등록 후 별도 연결에서 일본 수집 실행과 정식 상품 모두 0건을 확인했다. [개발 환경 등록 스크립트](../../db/market-packs/jp-higo-kagoshima/register.py)

로컬 API는 상품명과 설명서가 짝지어진 일본어 목록을 읽는다. Worker는 이 경로에서 선택한 PDF를 받을 때 현재 목록의 상품명과 URL을 재확인한다. 누락·이름 변경·다른 문서로의 이동·접근 거부를 구별한다. 확인된 이름과 담보·연이율·통화 등 필수 근거가 맞아야 정식 상품이 될 수 있다. 일본이라는 이유로 JPY를 채우지 않는다.

가고시마 종합 목록 전체를 재생하면 대조표에서 이 목록에 연결한 6개 유형의 설명서 26건을 모두 다시 찾는다. 결제성예금 3건, 저축예금 1건, 정기예금 9건, 주택대출 2건, 개인대출 8건, 한도대출 3건이다. 각 PDF의 원문 검증과 상품 승인은 이후 단계다.

가고시마 카드론 S의 상환계좌 불필요형에서는 같은 원문에 있는 엔화 한도, 8개 연이율 구간, 변동금리 개정·상한, 담보·보증인 조건 및 가입 조건을 재생했다. 상환계좌 인출형과 사업자 유형에 같은 근거를 적용하면 자동 제외한다. 별도 프리론 설명서의 최대 금리 인하폭은 적용 연이율을 입증하지 않는다. 보존 PDF의 SHA-256은 회귀 테스트에서 검증한다. [카드론 원문](https://www.kagin.co.jp/library/kojin/loan/pdf/2026/cardloanS_huyo.pdf) · [프리론 원문](https://www.kagin.co.jp/library/kojin/loan/pdf/2026/04/freeloan.pdf) · [원문 재생 테스트](../../worker/pipeline/tests/test_japan_market.py)

## 전상품 수집에 남은 조건

| 대상 | 수집 전 확인할 조건 |
| --- | --- |
| 히고은행 | 실제 수집 Worker가 은행에서 허용한 경로로 목록과 공식 상세를 읽을 수 있어야 한다. 공개 웹 색인에서 확인한 이름은 현재 수집 실행의 원문 근거를 대신할 수 없다. |
| 예금·대출 | 공식 설명서가 금리표·수수료표를 가리키면 같은 상품, 통화, 기간, 대상 고객의 근거를 연결해야 한다. “당행 소정 금리”만 공개하거나 한도·담보·인출 조건이 불명확하면 해당 후보는 자동 제외한다. 두 은행에서 8개 유형 각각의 정식 상품 생성까지 검증된 상태는 아니다. |
| 데빗카드 | 자체 지급결제 상품에는 계좌 즉시 인출, 결제 통화, 연회비 및 면제 조건을 표현할 수 있는 유형이 필요하다. 현재 상품군은 예금·여신이다. [히고 데빗](https://www.higobank.co.jp/landing/jcbdebit/) · [가고시마 데빗](https://www.kagin.co.jp/jcbdebit_kagin/index.html) |
| 구조화예금·외환·무역금융 | 선물환 연계예금, 외환선도, 신용장·은행보증 등은 거래 통화쌍, 만기·인도 방식, 수수료·중도종료 및 은행 역할을 보존하는 비교 기준이 필요하다. 일반 정기예금이나 무담보대출로 등록하면 조건이 손실된다. |
| 법인·특수목적 상품 | 보도자료로만 확인한 상품, 사모채의 발행·인수·주선 역할, 개인·법인 페이지의 판매 상태가 다른 상품은 상품별 현재 원문에서 확인해야 한다. 중개 펀드·보험, 단순 신청·송금 안내, 신규 취급 종료는 활성 상품 집계에서 제외한다. |

배포 후 첫 유상 실행은 별도 운영 단계다. 두 은행의 접근 상태를 실행 환경에서 각각 확인하고, 가고시마 한도대출 단일 범위에서 현재 목록·스냅샷·필드 증거와 자동 승인 또는 제외 사유를 확인하면 이번 로컬 재생과 비교할 수 있다. 이번 준비 작업은 개발 DB 설정과 로컬 코드·검증까지 적용했다. [은행 상품 수집 검증 가이드](../../descent/은행_상품_수집_검증_가이드.md)

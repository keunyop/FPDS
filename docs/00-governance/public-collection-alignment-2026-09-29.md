# SwitchaBank 변경에 따른 CA/US 수집 정합성 점검

날짜: 2026-09-29
범위: 기존 캐나다·미국 상품, 수집/검증 프롬프트와 금융 의미, 제한된 기존 데이터 보정.

## 결과

- 활성 원본 상품 **308개(CA 190 / US 118)**와 공개 상품 **216개(CA 165 / US 51)**를 읽기 전용으로 점검했다.
- 공식 상품 확인은 **8개 상품**으로 제한했다. 확인된 **6개 상품, 24개 필드**를 버전·변경 이력과 함께 보정했다.
- 보정 후 공개 상품은 **CA 164 / US 50**이다. 필수 금리 근거가 부족해진 두 상품은 공개에서 제외했다. 원본·과거 버전은 보존했다.
- 나머지 **302개 원본 상품**, 대상 외 **293개 스냅샷 행**과 모든 기존 상품 검증일이 그대로임을 확인했다.
- 전체 재수집, 신규 상품 수집, 프로젝트 수집/검증용 AI API 호출은 **0회**다. 코드 배포는 하지 않았다. 데이터 보정은 공유 DB에 적용했고 실제 SwitchaBank 공개 API에서 확인했다.

## Public 변경과 수집의 차이

| 최근 Public 요구 | 확인한 차이 | 반영 |
|---|---|---|
| Home/finder의 연이율·APY 및 만기별 비교 | 필수 필드 중심 프로필이 계산 기준·조건 일부를 요청하지 않음 | 같은 근거 수집 과정에서 보충 필드도 요청 |
| 두 상품 계산기 | 연이율과 APY, 복리, 프로모션·구간 금리 구분 필요 | 기준을 추정하지 않는 공통 프롬프트와 근거 검사 |
| GIC/CD 만기 선택 | Marcus의 10일 금리보장 기간이 만기로 저장됨 | 금리보장·입금기한·유예기간·위약금 일수를 만기에서 제외 |
| 은행 이동 전 조건 확인 | 개설 최소금액과 유지 최소잔액 혼용 위험 | 별도 추출, 명시된 0만 허용, 면제와 기본 수수료 분리 |
| Loan 담보 조건 | 선택적 담보 여부가 수집/미국 투영에서 빠질 수 있음 | 공식 근거가 있을 때만 보충 수집·투영 |
| 비교 저장·가이드·UI 개선 | 신규 금융 필드가 필요하지 않음 | 추가 수집 없음 |
| 상품 검증일 표시 | 부분 필드 보정은 전체 재검증이 아님 | 기존 검증일 유지, 새 스냅샷 시각과 구분 |

`fpds_market_profile.py`의 프로필은 `2026-09-29-v5`다. 기존 필수 승인
항목은 유지한다. 보충 조건은 이미 읽는 근거·공식 페이지에서 확보하고,
누락만을 이유로 추가 검색·재시도 또는 Review 항목 확대를 하지 않는다.
기존 한 번의 공식 근거 확인 호출, 출처·인용문·국가·상품 경계와 비용 제한을
그대로 사용한다. 조건이 없으면 Public의 비교/계산 제한도 유지한다.

공통 프롬프트는 연이율/APY, 계산·지급·복리 주기, 만기별 금리·최소금액,
프로모션, 기본 수수료·면제, 최소잔액·개설금액, 담보와 중도해지를 구분한다.
연이율 설명·구간 조건·프로모션 기간은 원문 인용에 실제로 있어야 한다.
할인율·증분 보너스·상한이 있는 연간 적립 보너스를 전체 금리로 승인하지 않는다.

## 비용과 남은 작업

광고문구·신청 절차·부가 혜택을 채우기 위한 수집을 하지 않았다. 같은 상품의
중복 레코드를 보강해 비교 개수를 늘리지 않았고 기존 Review의 미승인 US
후보 3건도 승인하지 않았다. 이 작업은 그 승인 경계를 변경하지 않는다.

| 점검 항목 | 보정 전 | 보정 후 |
|---|---:|---:|
| CA 공개 예금의 연이율 기준 미확인 | 15 | 13 |
| US 공개 예금의 연이율 기준 미확인 | 1 | 0 (해당 상품 공개 제외) |
| US 공개 Savings의 최소잔액 미확인 | Marcus 포함 | Marcus 보완 |
| US CD의 만기 옵션 | 충돌하는 만기·프로모션으로 사용 불가 | 9개 정확한 만기 옵션 |

남은 값이 없다는 사실은 오류나 0을 뜻하지 않는다. CA의 프로모션 12개,
구간 금리 5개, 시장연동 2개와 US 구간 금리 2개는 단순 비교/계산에서 계속
제한된다. 담보 미공개(CA 19 / US 14)나 개설 최소금액 미공개를 전부 채우기
위해 재수집하지 않는다. 기존 검증일 만료 표시도 그대로 남는다.

이번 표본의 CIBC GIC는 직접 HTML에 미해결 금리 토큰이 있었고, TD는
금리표에서 0.010%를 확인했지만 접근 가능한 자료에서 필요한 명시적 연이율
기준을 충분히 확보하지 못했다. 새 값을 추정하지 않았다. Manulife의 기존
서로 맞지 않는 GIC 만기/행 최소금액, Vancity의 같은 만기·다른 조건 행,
기타 과거 상품의 최신성은 다음 소규모 점검 대상이다. 이번 결과는 전체
상품의 현행 금리 인증이나 모든 Home 조건에 5개 상품을 채웠다는 뜻이 아니다.

## 반복 가능한 운영

```powershell
# 모델/은행 호출 없이 현재 공개 조건 누락과 비공개 필수 누락을 점검
uv run python scripts/maintenance/public_collection_gap_report.py --output tmp/public-alignment/gaps.json

# 고정된 6개 보정: 기본은 롤백; 이미 적용됐으면 아무 변경 없이 종료
uv run python scripts/maintenance/public_alignment_20260929.py

# 이 날짜 명세의 테스트
uv run python -m unittest scripts.maintenance.test_public_alignment_20260929 -q
```

향후에는 오류가 확인된 값 → 기존 근거로 보완 가능한 조건 → 영향이 큰
공식 상품 페이지 순으로 점검한다. 보고서의 상품 제안은 실행 명령이 아니다.
한 번에 CA/US 합계 20개 이하, 상품당 보조 페이지 2개 이하를 작업 기준으로
삼고, 접근 실패·서로 다른 상품 조건·개별 견적이면 보류한다. 전체 재수집과
주기 실행을 추가하지 않는다. 이 수량은 이번 작업 기준이며 전역 설정을
강제로 바꾼 것은 아니다.

## 검증

- Worker 전체 536개, API 전체 502개, Public 74개 테스트 통과.
- 보정·점검 도구 6개 테스트 통과. 버전/해시 불일치, 다른 도메인, 누락 근거,
  필수 항목 없는 공개, URL 중복과 0/미확인 구분을 검증했다.
- 실제 DB에서 롤백 시험 후 적용, 재실행 무변경, 이전 버전 보존, 다른 원본
  302개와 다른 투영 293개 보존, 검증일 미갱신 확인.
- 실제 공개 HTTP에서 CA 164 / US 50 전체 행의 금리·수수료·최소잔액·조건과
  저장된 공개 직렬화 결과 일치 확인.
- UI 파일과 API 응답 구조는 바꾸지 않았다. 새로운 브라우저 레이아웃 검사,
  프런트엔드 빌드나 코드 배포는 이 작업에서 실행하지 않았다.

- Repository doctor, `git diff --check`, 신규 파일 UTF-8·공백 검사 통과.

상태: 소규모 재수집·자동 반영·운영 Public 조회 검증 완료. 추가 코드 배포 필요.

## 결과

기존 등록 상품 원문 2개(TD 미국달러 카드, Vancity 미국달러 계좌)로 시작했다.

확인된 결함을 수정하며 Vancity만 제한적으로 재실행했다. 총 수집 실행 5개이며
범위는 계속 같은 원문 2개였다. 모든 이전 제외 결과와 원문을 비공개 기록에 남겼다.

- **Vancity USD Chequing 1개 자동 반영**: 국가 CA, 통화 USD, 월 수수료 숫자 0,
  월 무료 거래 횟수 정수 1. 금리·최소 잔액·추가 속성은 근거 부족으로 공개하지 않는다.

  정상 자동 승격 서비스가 새 버전과 Updated 변경 이력을 만들었다.
  독립 조회로 다른 354개 상품의 비활성 상태와 버전이 그대로임을 확인했다.

- 이번 실행의 새 review task **0건**, 전체 미처리 review **0건**.
  사람의 값 수정·수동 승인·검토 API 호출은 없었다.

## 실제로 수정한 문제

1. `One free Everyday Transaction per month`를 정수 1로 입증하지 못하던 검사를 수정했다.
   정확한 원문 인용은 유지한다. 범위·조건·분수·복합 숫자 일부를 정수로 잘못 읽지 않는다.
2. 수수료와 별개인 `Great if` / `You want` 적합성 안내를 수수료 면제 조건으로
   오인하지 않는다. 실제 잔액·면제·자격 조건은 계속 검사한다.
3. `transfers between accounts`의 between을 숫자 범위로 오인하던 검사를 수정했다.
4. Annual Fee 또는 연간 이자 지급일을 금리의 연이율 단위 근거로 사용하지 않는다.
5. 추출 프롬프트에 필드별 반환, 원문의 글자형 횟수와 JSON 정수 예시, 정확한
   근거 ID·인용문 보존을 명시했다. 설명문에만 언급된 사실은 수집된 값으로 인정하지 않는다.
   누락된 필드에는 인용·출처·자료형·근거 ID 등의 구체적인 탈락 사유를 비공개로 기록한다.

구조화 출력도 의미상 오류가 가능하므로 형식 일치만으로 승인하지 않는다.
명확한 예시와 별도 검증을 유지한다.
[OpenAI 공식 문서](https://developers.openai.com/api/docs/guides/structured-outputs#handling-mistakes)를 참고했다.
모델과 reasoning 설정은 변경하지 않았다.

## 원문 재처리와 감사 이력

일부 후속 AI 응답은 올바른 사실을 설명하면서도 정확하지 않은 인용문을 반환했다.
이 응답은 그대로 제외했다. 앞선 추출에 정확한 인용과 정수 1이 보존되어 있어
**그 실행 자체의 원본 추출**을
수정된 정규화·검증·자동 승격 서비스로 재처리했다. 다른 실행의 자료를 섞지 않았다.

- 재처리 run: `run_20260930_161106_vancity_chequing_collect_pjFpxGHA`
- 해당 실행의 원본 추출 SHA-256:
  `e3c27365d2a580b7542821f44834d1adc656b9473b2f09501805c1ff8e0a4d08`
- 원본 산출물의 run ID, 정수 타입, 정확한 인용을 먼저 검증했다.
- 이전 후보/실행 상태를 `tmp/accuracy-pilot-reprocess-before.json`에 보존했다.
- DB에 `accuracy_pilot_reprocessing_started/completed` 서비스 감사 이벤트를 남겼다.
- 서비스가 후보를 정규화하고 자동 검증 결과를 새로 계산했다. 검증 결과를 직접 작성하거나
  통과 점수를 지정하지 않았다. 자동 승격 1건과 집계 요청·완료를 독립 DB 조회로 확인했다.
- 원문·모델 실행·후보·스냅샷·HTTP 확인 자료는 ignored `tmp/accuracy-pilot-*`에 있다.

## 검증과 남은 범위

- Worker **560개**, API **535개** 테스트 통과. 새 회귀 테스트 5개는 실제 원문 구조,
  조건부 실패, 잘못된 자료형·숫자 일부 해석·연이율 근거·모델 필드 누락을 포함한다.
- repository doctor, foundation baseline, diff 검사 통과.
- 운영 API/BFF/목록/상세 확인. UI 소스 변경은 없으며 추가 UI 빌드를 주장하지 않는다.
- 새 코드로 실행한 로컬 수집의 실제 데이터 반영은 완료했다. 앞으로 배포 환경에서
  같은 동작을 쓰려면 변경된 API/worker 수집 런타임을 배포해야 한다.
- 초기 355개 전체를 재수집한 결과가 아니다. 나머지 상품을 일괄 재활성화하지 않았다.
  이 파일럿만으로 모든 은행/상품 표현의 정확도를 보장하지 않는다.
